# A Big-Data Pipeline for Bank-Failure Early Warning (FDIC, 1984–2026)

BFT65B – Big Data Analytics in Finance, final individual report
**Author:** Nguyễn Trung Kiên – student ID 11230982 – National Economics University

An end-to-end, reproducible pipeline on the public FDIC BankFind data:
acquisition → columnar storage → automated data-quality audit → point-in-time bank-quarter panel →
Polars processing (benchmarked against pandas, reproduced in PySpark) → leak-free features →
time-ordered validation of an early-warning model.

## Repository layout

| Path | What it does | Report part |
|---|---|---|
| `src/01_download.py` | Resumable download from `https://api.fdic.gov/banks` (Financials 1984Q1–2026Q2, Failures, Institutions); per-quarter completeness manifest | 1 |
| `src/02_storage.py` | Explicit schema, curated Parquet layer (zstd, partitioned by year); CSV vs Parquet benchmark | 1 |
| `src/03_quality.py` | Automated data-quality report → `results/dq_report.md` | 2 |
| `src/transforms.py` | Core Polars transformations (clean, de-cumulate YTD flows, label, exit types) | 2–3 |
| `src/04_panel.py` | Clean bank-quarter panel with failure label and exit types | 2 |
| `src/05_benchmark.py` | pandas vs Polars eager / lazy / streaming, equality check, scaling ×1–×8 | 3 |
| `notebooks/08_spark_demo.ipynb` | PySpark reproduction, row-level match with Polars, physical plan, MLlib demo | 3, 5 |
| `src/features.py`, `src/06_features.py` | CAMELS-style point-in-time features + automatic look-ahead (truncation) test | 4 |
| `src/07_model.py` | Walk-forward CV on the development period, cost-based threshold, single test evaluation | 5 |
| `results/` | All tables (CSV/JSON/Markdown) and figures produced by the pipeline (no raw data) | – |
| `report/` | `build_report.py` and the generated report (DOCX + PDF) | – |

Data files are **not** committed (`data_raw/`, `data/` are git-ignored); they are rebuilt by the scripts.

## How to reproduce

Tested on Windows 11, Python 3.13, 16 GB RAM, 8 cores. Measured runtime of `run_all.py`: ≈ 25 min for the download, then ≈ 25 min for all other steps
(storage benchmark 4.5 min, engine benchmark 3 min, modelling 8 min, Spark notebook ≈ 6 min).

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate      Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt

python run_all.py                    # everything, including the download and the Spark notebook
# or step by step:
python src/01_download.py            # resumable: re-run to continue after an interruption
python src/02_storage.py
python src/03_quality.py
python src/04_panel.py
python src/05_benchmark.py           # add --quick for a 1-repeat run without the scaling test
python src/06_features.py
python src/07_model.py
python -m ipykernel install --sys-prefix --name bft65b   # kernel inside the venv (done by run_all.py)
python notebooks/make_spark_notebook.py
python -m nbconvert --to notebook --execute --inplace --ExecutePreprocessor.kernel_name=bft65b notebooks/08_spark_demo.ipynb

python report/build_report.py       # regenerates the report (DOCX) from results/
```

**PySpark** needs a Java 17 runtime. Set `JAVA_HOME`, or unzip a JDK 17 into `~/tools/jdk-17*`
(picked up automatically by `src/common.py`). Without Hadoop's `winutils.exe`/`hadoop.dll`, Spark on Windows
cannot list directories or write files, so the notebook passes the partition files explicitly with `basePath`
and only reads; Hadoop binaries are therefore not required. On Linux/Colab the same code runs unchanged.

**Windows on ARM:** when x64 Python runs emulated, Polars' import-time CPU probe fails
(`unknown feature flag: 'sse3'`). `src/common.py` sets `POLARS_SKIP_CPU_CHECK=1`, which skips only that probe.

Seeds are fixed (`SEED = 42` in `src/common.py`). All results in `results/` are regenerated by the run.

## Data

* Source: FDIC BankFind Suite API, `https://api.fdic.gov/banks` (no key). Field dictionary copied to `docs/fdic_dictionary/`.
* Downloaded on 2026-11-06: 1,682,616 Financials rows (170 quarters, 24,064 banks), 4,117 Failures, 27,835 Institutions.
  Row counts match the API totals for every quarter (`data_raw/fdic/manifest_financials.json`).
